# KainoTranslator

[English](README.md) | [Русский](README.ru.md) | **日本語** | [Deutsch](README.de.md) | [Polski](README.pl.md)

画面上の指定した矩形範囲をOCRで認識し、その上にリアルタイム翻訳をオーバーレイ表示する、軽量な
Windowsデスクトップアプリです。ゲームの字幕、会話ウィンドウ、動画の字幕、その他画面上の
あらゆる外国語テキストに対応しています。

- ホットキーでキャプチャ範囲を選択、翻訳のオン/オフ、設定画面の呼び出しができます。
- テキスト認識には **Windows OCR**（推奨・デフォルト、Windows標準搭載でセットアップ不要）を
  使用しますが、お好みで従来型の **Tesseract** / **EasyOCR** エンジンも選択できます。
- 翻訳には **DeepL**、**Google翻訳**、**Yandex Translate**、**Papago** が使えます。
- 英語、日本語、中国語（簡体字・繁体字）、韓国語、ロシア語を強力にサポートし、さらに約25の
  言語（フランス語、ドイツ語、スペイン語、イタリア語、ポルトガル語、オランダ語、ポーランド語、
  トルコ語、ベトナム語、タイ語、インドネシア語、アラビア語、ヒンディー語、ウクライナ語、その他
  ほとんどのヨーロッパ言語）に対応 — 完全なリストは `Models/LanguageCatalog.cs` を参照してください。
- Google翻訳の無料エンドポイントがIPベースでレート制限されるのを防ぐための、リクエストを
  ローテーションするプロキシリスト（任意設定）。
- ゲームの上に重ねてもフォーカスや入力を奪わない、クリックスルー対応・ボーダーレス表示に優しい
  オーバーレイ。

> **注意：** 現在、アプリ自体のインターフェースはロシア語のみです。以下で言及するタブ/メニュー名は、
> アプリに実際に表示される（ロシア語の）名称をそのまま記載し、初出時のみ括弧内に日本語訳を添えています。

## 動作環境

- Windows 10（2018 Update / 1809以降）またはWindows 11。
- ビルドには [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) が必要です。
- Visual Studio 2022（17.8以降）で開いて実行するのが最も簡単ですが、.NET CLIでも問題ありません。

## ビルドと実行

```
cd KainoTranslator
dotnet restore
dotnet build -c Release
dotnet run -c Release
```

または、Visual Studioで `ScreenTranslator.sln` を開いてF5キーを押してください。このアプリに
メインウィンドウはありません — **システムトレイ**（タスクバー右下）から動作します。トレイ
アイコンを右クリックしてメニューを開くか、下記のホットキーを使用してください。

起動時にウィンドウが表示されないのは仕様です。トレイアイコンが見当たらない場合は、タスクバーの
「隠れているインジケーター」矢印（^）を確認してください。

## デフォルトのホットキー

| 操作                                       | デフォルトの組み合わせ |
|---------------------------------------------|-----------------|
| キャプチャ範囲を選択                          | `Ctrl+Shift+A`  |
| リアルタイム翻訳のオン/オフ                    | `Ctrl+Shift+S`  |
| 範囲を一度だけ翻訳（ワンショット）              | `Ctrl+Shift+D`  |
| 設定を開く                                   | `Ctrl+Shift+O`  |

4つとも **Настройки > Горячие клавиши**（設定 > ホットキー）タブで変更できます — 欄をクリックして
希望のキーの組み合わせを押してください（Ctrl、Alt、Shift、Winのいずれかの修飾キーを必ず含める
必要があります）。ホットキーの登録に失敗した場合（トレイのバルーン通知で表示されます）、その
組み合わせはすでに他のアプリで使用されています。別の組み合わせを選んでください。

「範囲を一度だけ翻訳」ホットキーを使うと、画面上の任意の範囲を選択して一度だけ翻訳できます
（例：画面の別の場所に表示されたテキストなど）。メインのキャプチャ範囲には影響せず、すでに
リアルタイム翻訳が動作中であってもそれを中断しません。

## 初回セットアップ

1. アプリを起動します（トレイにアイコンが表示されます）。
2. `Ctrl+Shift+A` を押して、翻訳したい字幕・会話部分を矩形で選択します。
3. `Ctrl+Shift+O` を押して設定を開きます：
   - **Перевод**（翻訳）— OCRエンジン（デフォルトはWindows OCR）、認識元の言語、翻訳サービス、
     翻訳先の言語、選んだ翻訳サービスのAPIキー（下記参照）を設定します。
   - 保存します。
4. `Ctrl+Shift+S` を押してリアルタイム翻訳を開始します。翻訳されたテキストがキャプチャ範囲付近の
   オーバーレイに表示されます。

## OCRエンジン

- **Windows OCR（推奨・デフォルト）** — ダウンロード不要ですが、選択した言語のOCRコンポーネントを
  インストールしておく必要があります：**Windowsの設定 > 時刻と言語 > 言語と地域 > 言語の追加**から
  該当言語を追加し、その言語のオプションで **「光学式文字認識」** を有効にしてください。
  クリーンなUI/字幕テキストに対しては高速かつ概ね最も高精度です。
- **Tesseract（レガシー）** — 完全オフラインで動作します。必要な言語の `.traineddata` ファイルを
  https://github.com/tesseract-ocr/tessdata_fast からダウンロードし、**Прочее**（その他）タブの
  Tesseractデータフォルダの設定先に配置してください（デフォルトはexeと同じ場所の `.\tessdata`）。
- **EasyOCR（レガシー）** — PATHにPython 3.9以降が必要です（または**Прочее**（その他）タブで
  実行ファイルを指定）。一度だけ `pip install easyocr` を実行してください。アプリは
  `Python\easyocr_worker.py` を起動し、EasyOCRのモデルをメモリに保持したまま、標準入力の1行ごとに
  1件の認識リクエストに応答します — これにより毎フレーム（低速な）モデルの再読み込みを避けられます。
  GPUアクセラレーションは任意で、CUDA対応のPyTorchビルドが必要です。

## 翻訳サービスとAPIキー

| 翻訳サービス | 必要なもの | 備考 |
|---|---|---|
| **DeepL** | deepl.com/pro-api のAPIキー（無料枠あり） | 有料のProキーを持っている場合のみ「Pro endpointを使用」をオンにしてください — 無料キーは無料エンドポイントのままにする必要があります。 |
| **Google翻訳** | 特に不要 | Googleの無料Webエンドポイントですぐに動作します。無料エンドポイントの代わりに確実な稼働率/クォータが欲しい場合はCloud Translation APIキーを追加してください。 |
| **Yandex Translate** | Yandex CloudのAPIキー + Folder ID | 両方とも必須です。 |
| **Papago** | NAVER Cloud PlatformコンソールのClient ID + Client Secret | Papagoは限られた言語ペアのみサポートしており、主に韓国語/英語/日本語/中国語を経由します — サポートされている翻訳先言語のみが選択肢として表示されます。 |

## プロキシ

**Прочее**（その他）タブの一番下にあるプロキシリストには、1行に1つずつプロキシを入力します：
```
http://1.2.3.4:8080
http://user:pass@1.2.3.4:8080
1.2.3.4:8080
```
空欄のままにすると直接接続します（デフォルト）。これは主にGoogleの無料エンドポイントで有用です。
このエンドポイントには公式のレート制限保証がなく、高速な連続アクセスでリクエストが拒否され始める
ことがあります — 複数のプロキシをローテーションする（リストが空でない場合デフォルトで有効）ことで、
異なるIPに負荷を分散できます。

## ゲームでの使用について

- **ゲームを「ボーダーレス」または「ウィンドウモード」で起動してください。** ほとんどのゲームは
  `Alt+Enter` またはディスプレイモードの設定で切り替えられます。これが最も重要なポイントです。
- **排他的フルスクリーン**モードでは、画面キャプチャとオーバーレイの両方が正しく動作しないことが
  あります。一部の排他的フルスクリーンのゲームは通常のWindowsコンポジター（DWM）を経由しないため、
  キャプチャ画像が真っ黒になったり、オーバーレイが上に描画されなかったりします。ボーダーレス/
  ウィンドウモードは通常のウィンドウと同様にDWM経由で描画されるため、キャプチャとオーバーレイの
  両方が正しく動作します。最近のWindows/DirectXは真の排他的フルスクリーンを避ける傾向にありますが、
  ゲームが「フルスクリーン」しか用意していない場合、オーバーレイの表示がおかしければ
  ウィンドウ/ボーダーレスモードを試してください。
- オーバーレイは**デフォルトでクリックスルー**（**Оформление**（見た目）タブで切り替え可能）
  なので、下にあるゲーム向けのマウスクリックやキーボード入力をブロックすることはありません。
- このアプリは**モニターごとのDPIを個別に考慮**するため、DPI設定が異なるマルチモニター環境や、
  範囲選択後にゲームを別のモニターに移動した場合でも、キャプチャ範囲とオーバーレイの位置は
  正確に保たれます（解像度/スケールが異なるモニターに移動した場合は範囲を選び直してください）。

## オーバーレイの見た目

**Оформление**（見た目）タブでは以下を設定できます：
- 位置（デフォルト：画面上部中央）、フォントサイズ、最大幅（デフォルト1200px）。
- テキストの色と背景色（16進数、例：`#FFFFFF`）— プレビュー付き、および背景の透明度
  （デフォルト20%。0%で背景は完全に不透明、100%で完全に透明）。
- 読みやすさのための、テキストの縁取り**または**影のどちらか一方（両方同時には設定不可、
  デフォルトはオフ）。
- テキストの更新が止まった場合にN秒後オーバーレイを自動的に非表示にする機能（任意）。

## パフォーマンスに関する注意

- ポーリング間隔（デフォルト0.3秒、**Перевод**（翻訳）タブで秒単位で表示）は、キャプチャ範囲を
  再チェックする頻度を制御します。
- 「画面に変化がない場合はOCR/翻訳を再実行しない」（デフォルトでオン）は、キャプチャした各
  フレームの縮小版をハッシュ化し、変化がない場合はOCRと翻訳APIの呼び出しを完全にスキップします
  — ほとんどの字幕/会話テキストは1秒以上静止しているため、これによって速いポーリング間隔でも
  CPU負荷と翻訳API使用量の両方を低く抑えられます。
- 認識されたテキストは、（些細な空白/改行の違いを無視した上で）2回連続の確認で同じ内容と
  判定されて初めて翻訳されます — これにより、1回のノイズの多いOCR読み取りのせいで表示中の翻訳が
  ちらついたり変わったりすることを防ぎます。副次的な効果として、画面上で徐々に表示されていく
  （タイプライター効果の）字幕は、表示が止まった時点、つまり表示が完了した時点で初めて翻訳
  されます — これは別途実装した機能ではなく、同じ安定性チェックの自然な結果です。
- 同一の認識テキストが繰り返された場合も、無駄な翻訳リクエストをスキップします。
- 体感的な遅延のほとんどはOCRと翻訳の通信往復にかかる時間です。Windows OCRはローカルで動作し、
  3つのエンジンの中で通常最も高速なため、速度とシンプルさの両方を重視する場合に最適な選択です。

## プロジェクト構成

```
KainoTranslator/
  App.xaml(.cs)              - トレイアイコン、ホットキー配線、全体の統括
  TranslationEngine.cs        - キャプチャ -> OCR -> 翻訳 -> オーバーレイのループ
  Capture/                    - 範囲選択UI + 画面キャプチャ + フレームのハッシュ化
  Ocr/                        - IOcrEngine + Windows OCR / Tesseract / EasyOCR の実装
  Translation/                - ITranslator + DeepL / Google / Yandex / Papago の実装、プロキシ管理
  Overlay/                    - 常に最前面に表示される翻訳テキストのオーバーレイウィンドウ
  Hotkeys/                    - グローバルホットキーの登録（RegisterHotKey）
  SettingsUi/                 - 設定ウィンドウ
  Models/                     - AppSettings（%AppData%\KainoTranslator\settings.json に保存）、LanguageCatalog
  Python/easyocr_worker.py    - EasyOCRワーカースクリプト（EasyOCRエンジン使用時のみ必要）
```

## 既知の制限事項・トラブルシューティング

- Windows OCRを使うには、Windowsの設定から該当言語のOCR機能をインストールしておく必要が
  あります — インストールされていない場合、アプリは黙って失敗するのではなく、その旨を明確に
  通知します。
- Google無料エンドポイントとPapagoの言語ペアの制限については上記の通りです。翻訳サービスが
  リクエストを拒否した場合、アプリは黙って失敗するのではなく、（トレイ通知で）分かりやすい
  エラーメッセージを表示します。
- ホットキーが反応しない場合、おそらくそのキーの組み合わせはすでに別のアプリがシステム全体で
  登録済みです。設定で別の組み合わせを選んでください。
