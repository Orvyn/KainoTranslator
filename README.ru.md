# KainoTranslator

[English](README.md) | **Русский** | [日本語](README.ja.md) | [Deutsch](README.de.md) | [Polski](README.pl.md)

Лёгкое десктопное приложение для Windows, которое распознаёт текст в выбранной прямоугольной
области экрана и показывает перевод прямо поверх неё — подходит для субтитров в играх, диалогов,
титров в видео и любого другого иностранного текста на экране.

- Выбор области захвата, включение/выключение перевода и открытие настроек — всё по горячим клавишам.
- Распознаёт текст через **Windows OCR** (рекомендуемый вариант по умолчанию, встроен в Windows,
  не требует установки) либо через **Tesseract** / **EasyOCR**, если они вам больше нравятся.
- Переводит через **DeepL**, **Google Translate**, **Yandex Translate** или **Papago**.
- Хорошая поддержка английского, японского, китайского (упрощённого и традиционного), корейского
  и русского языков, плюс ещё ~25 языков (французский, немецкий, испанский, итальянский,
  португальский, нидерландский, польский, турецкий, вьетнамский, тайский, индонезийский,
  арабский, хинди, украинский и большинство других европейских языков — полный список в
  `Models/LanguageCatalog.cs`).
- Список прокси с чередованием запросов — в основном чтобы бесплатный способ Google Translate не
  блокировался при частых запросах.
- Прозрачное для кликов окно перевода, дружелюбное к оконному/безрамочному режиму игр — не
  перехватывает фокус и ввод.

## Требования

- Windows 10 (обновление 2018 / 1809) или Windows 11.
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) для сборки.
- Проще всего собрать и запустить через Visual Studio 2022 (17.8+), но подойдёт и .NET CLI.

## Сборка и запуск

```
cd KainoTranslator
dotnet restore
dotnet build -c Release
dotnet run -c Release
```

Либо откройте `ScreenTranslator.sln` в Visual Studio и нажмите F5. У приложения нет главного
окна — оно работает из **системного трея** (правый нижний угол панели задач). Кликните правой
кнопкой по значку для меню, либо используйте горячие клавиши ниже.

Отсутствие окна при запуске — это ожидаемое поведение; если не видно значка в трее, проверьте
стрелочку «Показать скрытые значки» на панели задач.

Подробная инструкция по сборке (для тех, кто не программирует) — в `build.bat`: дважды кликните
по нему, и готовый `KainoTranslator.exe` появится в папке `publish`.

## Горячие клавиши по умолчанию

| Действие                                   | Комбинация      |
|---------------------------------------------|-----------------|
| Выбрать область захвата                      | `Ctrl+Shift+A`  |
| Включить / выключить перевод                 | `Ctrl+Shift+S`  |
| Перевести область один раз (разово)           | `Ctrl+Shift+D`  |
| Открыть настройки                             | `Ctrl+Shift+O`  |

Все четыре можно изменить во вкладке **Горячие клавиши** — кликните по полю и нажмите нужное
сочетание (обязательно с модификатором: Ctrl, Alt, Shift или Win). Если горячая клавиша не
регистрируется (об этом сообщит уведомление в трее), значит эта комбинация уже занята другой
программой — выберите другую.

Горячая клавиша «перевести один раз» позволяет выделить любую область экрана и перевести её
единожды (например, текст, который появился в другом месте экрана), не трогая основную область
захвата и не прерывая непрерывный перевод, если он уже запущен.

## Первый запуск

1. Запустите программу (появится значок в трее).
2. Нажмите `Ctrl+Shift+A` и выделите прямоугольником область с субтитрами/диалогом.
3. Нажмите `Ctrl+Shift+O`, чтобы открыть настройки:
   - **Перевод** — движок распознавания (по умолчанию Windows OCR), исходный язык, переводчик,
     язык перевода, а также ключ API для выбранного переводчика (см. ниже).
   - Сохранить.
4. Нажмите `Ctrl+Shift+S`, чтобы запустить перевод. Переведённый текст появится в окне поверх
   области захвата (по умолчанию — вверху экрана по центру).

## Движки распознавания текста (OCR)

- **Windows OCR (рекомендуется, по умолчанию)** — ничего скачивать не нужно, но для выбранного
  языка должен быть установлен соответствующий компонент: **Параметры Windows > Время и язык >
  Язык и регион > Добавить язык**, и для этого языка включить **«Распознавание текста»** в его
  дополнительных возможностях. Быстрый и обычно самый точный вариант на чистом UI-тексте/субтитрах.
- **Tesseract (legacy)** — полностью офлайн. Скачайте файлы `.traineddata` для нужных языков с
  https://github.com/tesseract-ocr/tessdata_fast и положите их в папку, указанную во вкладке
  **Прочее > Папка с файлами языков (.traineddata)** (по умолчанию `.\tessdata` рядом с exe).
- **EasyOCR (legacy)** — нужен Python 3.9+ в PATH (либо указать путь к нему во вкладке
  **Прочее**) и один раз выполнить `pip install easyocr`. Программа запускает
  `Python\easyocr_worker.py`, который держит модель EasyOCR загруженной в памяти и отвечает на
  один запрос распознавания за строку stdin — это избавляет от повторной (медленной) загрузки
  модели на каждом кадре. Ускорение на видеокарте — по желанию, нужен PyTorch со сборкой CUDA.

## Переводчики и ключи API

| Переводчик | Что нужно | Примечания |
|---|---|---|
| **DeepL** | Ключ API с deepl.com/pro-api (есть бесплатный тариф) | Включайте «Pro endpoint» только если у вас платный ключ Pro — бесплатные ключи должны оставаться на бесплатном эндпоинте. |
| **Google Translate** | Ничего не требуется | Работает сразу через бесплатный веб-эндпоинт Google. Добавьте ключ Cloud Translation API для гарантированной доступности/квоты вместо бесплатного способа. |
| **Yandex Translate** | Ключ API + Folder ID из Yandex Cloud | Оба поля обязательны. |
| **Papago** | Client ID + Client Secret из консоли NAVER Cloud Platform | Papago поддерживает лишь ограниченный набор языковых пар, в основном через корейский/английский/японский/китайский — доступные варианты языка перевода будут показаны автоматически. |

## Прокси

Вкладка **Прочее > Список прокси** (в самом низу) принимает по одному прокси на строку:
```
http://1.2.3.4:8080
http://логин:пароль@1.2.3.4:8080
1.2.3.4:8080
```
Оставьте пустым для прямого подключения (по умолчанию). Это в основном полезно с бесплатным
способом Google, у которого нет официальной гарантии от ограничения частоты запросов и который
может начать отклонять запросы при интенсивном опросе — чередование через несколько прокси
(включено по умолчанию при непустом списке) распределяет нагрузку между разными IP.

## Использование с играми

- **Запускайте игру в режиме «Оконный без рамки» или «Оконный».** В большинстве игр режим можно
  переключить через `Alt+Enter` или в настройках экрана. Это самый важный совет.
- **Полноэкранный эксклюзивный режим** может странно вести себя и с захватом экрана, и с окном
  перевода, потому что некоторые такие игры обходят обычный композитор Windows (DWM) — снимок
  экрана может выйти чёрным, либо окно перевода не отобразится поверх игры. Оконный/безрамочный
  режимы рендерятся через DWM как обычное окно, поэтому и захват, и окно перевода работают
  корректно. Современные версии Windows/DirectX всё чаще избегают истинного эксклюзивного
  полноэкранного режима, но если игра предлагает только «Полноэкранный», попробуйте
  оконный/безрамочный, если окно перевода отображается неправильно.
- Окно перевода **прозрачно для кликов по умолчанию** (переключается во вкладке
  **Оформление**), поэтому оно никогда не блокирует клики мышью или ввод с клавиатуры,
  предназначенные для игры.
- Программа **учитывает DPI каждого монитора отдельно**, поэтому область захвата и положение
  окна перевода остаются точными даже при разных масштабах на разных мониторах или при
  перетаскивании игры между мониторами (если сменили монитор с другим разрешением/масштабом —
  выберите область заново).

## Оформление окна перевода

Вкладка **Оформление** позволяет настроить:
- Положение (по умолчанию — вверху экрана по центру), размер шрифта и максимальную ширину
  (по умолчанию 1200px).
- Цвет текста и цвет фона (в формате hex, например `#FFFFFF`) с превью, а также прозрачность
  фона (по умолчанию 20%; 0% — фон полностью непрозрачный, 100% — полностью прозрачный).
- Контур **или** тень для текста для читаемости на любом фоне (не одновременно) — по умолчанию
  выключено.
- Автоматическое скрытие окна перевода через N секунд, если текст не обновляется (по желанию).

## Заметки о производительности

- Интервал проверки области (по умолчанию 0.3 сек, вкладка **Перевод**, указывается в секундах)
  определяет, как часто перепроверяется область захвата.
- Опция «Не распознавать и не переводить повторно, если картинка не изменилась» (включена по
  умолчанию) хеширует уменьшенную версию каждого захваченного кадра и полностью пропускает OCR и
  запрос к переводчику, если ничего не изменилось — это позволяет держать быстрый интервал
  проверки дешёвым и по нагрузке на процессор, и по расходу запросов к API перевода, поскольку
  субтитры/диалоги обычно не меняются секунду и дольше.
- Распознанный текст должен совпасть (без учёта мелких отличий в пробелах/переносах строк) на
  двух проверках подряд, прежде чем будет переведён — это останавливает мерцание/изменение уже
  показанного перевода из-за случайного шума в одном кадре распознавания. Побочный эффект:
  субтитры, которые печатаются на экране постепенно, переводятся только когда перестают
  меняться, то есть когда допечатались полностью — это не отдельная функция, а естественное
  следствие той же проверки на стабильность.
- Повторный одинаковый распознанный текст также пропускает лишний запрос на перевод.
- Ощутимая задержка — это в основном время на OCR и сетевой запрос к переводчику; Windows OCR
  работает локально и обычно является самым быстрым из трёх движков, поэтому это лучший выбор,
  когда важны и скорость, и простота.

## Структура проекта

```
KainoTranslator/
  App.xaml(.cs)              - значок в трее, горячие клавиши, общая координация
  TranslationEngine.cs        - цикл захват -> OCR -> перевод -> окно перевода
  Capture/                    - выбор области + захват экрана + хеширование кадра
  Ocr/                        - IOcrEngine + реализации Windows OCR / Tesseract / EasyOCR
  Translation/                - ITranslator + реализации DeepL / Google / Yandex / Papago, менеджер прокси
  Overlay/                    - окно перевода поверх остальных окон
  Hotkeys/                    - регистрация глобальных горячих клавиш (RegisterHotKey)
  SettingsUi/                 - окно настроек
  Models/                     - AppSettings (хранится в %AppData%\KainoTranslator\settings.json), LanguageCatalog
  Python/easyocr_worker.py    - скрипт-воркер EasyOCR (нужен только при использовании движка EasyOCR)
```

## Известные ограничения / решение проблем

- Для Windows OCR должен быть установлен компонент распознавания для нужного языка через
  параметры Windows — программа явно сообщит об этом, если компонент отсутствует, вместо того
  чтобы молча не сработать.
- Ограничения бесплатного эндпоинта Google и языковых пар Papago описаны выше; программа
  показывает понятные сообщения об ошибках (через уведомление в трее), а не падает молча, когда
  переводчик отклоняет запрос.
- Если горячая клавиша не срабатывает, скорее всего, эту комбинацию уже заняла другая
  программа — выберите другую в настройках.
